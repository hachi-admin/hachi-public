OAuth2 セットアップ
  1. Gmail で IMAP を有効化: 設定 → すべての設定 → メール転送と POP/IMAP → IMAP を有効にする
  2. GCP Console で OAuth2 デスクトップクライアントを作成し、クライアント ID / シークレットを hachi-sec-017/018 に保存
  3. node scripts/gmail-oauth-setup.js をローカルで実行し、リフレッシュトークンを hachi-sec-019 に保存
  4. Cloud Run に --update-secrets HACHI_SEC_017=hachi-sec-017:latest ... を追加して再デプロイ
OAuth2 設定後はアカウントカードの OAuth バッジが ● に変わります。

Discord チャンネル
チャンネルレジストリ・エージェントルーティング
Bot の表示範囲 — 必要な Discord 権限 ▼
問題: Bot はロールがアクセスできるチャンネルのみ表示されます。
解決方法:
  1. サーバー設定 → ロール → 「Bot」ロールを作成
  2. 有効化: View Channels, Read Message History, Send Messages, Send in Threads, Embed Links, Manage Channels, Manage Messages
  3. サーバーメンバーで Bot にこのロールを割り当て
  4. プライベートチャンネルの場合: そのチャンネルの権限オーバーライドに Bot ロールを追加
必要な権限 (integer: 3271745):
View Channels Read Message History Send Messages Send in Threads Create Threads Embed Links Attach Files Add Reactions Manage Channels Manage Messages
